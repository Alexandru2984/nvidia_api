# Security policy

## Supported version

Security fixes are applied to the current `main` branch. Older commits and
private deployments are not maintained as separate supported releases.

## Reporting a vulnerability

Please use the repository's private
[GitHub security advisory form](https://github.com/Alexandru2984/nvidia_api/security/advisories/new).
Do not open a public issue for a suspected vulnerability and do not include
production credentials, user data, or destructive proof-of-concept payloads.

Include the affected endpoint or component, reproduction steps, likely impact,
and any suggested mitigation. Reports will be acknowledged as soon as practical;
remediation timing depends on severity and reproducibility.

Good-faith, non-destructive research is welcome. Do not access other users'
data, degrade availability, use social engineering, or test infrastructure that
is outside `aichat.micutu.com` without explicit authorization.
